# Time Tracker

Toggl Track 風の個人用タイムトラッカー。バックエンド不要、ブラウザだけで完結します。

## 使い方

`index.html` をブラウザで開くだけです。
ビルドやサーバ起動は不要です。HTML・CSS・JS は 1 ファイルにまとめてあります。
Vue 3 と VueUse のみ CDN から読み込むため、初回だけインターネット接続が必要です（以降はブラウザキャッシュで動きます）。
[github pages](https://kbtaniguchi.github.io/time-tracker/)にもdeployしているので、気にならなければそちらを使ってもよいです。 

## 画面構成

1 画面の 2 カラム構成（狭い幅では 1 カラムに折り返し）。

- **左**: エントリー（カレンダー / リスト切替）とレポート。
- **右上の ⚙ ボタン**: プロジェクトとデータ管理をスライド式ドロワーで開閉（普段は隠れています）。Esc / 背景クリックで閉じます。

## 機能

### エントリー

カレンダー表示とリスト表示を見出し右のトグルで切り替えます。**元に戻す / やり直し**（Ctrl+Z / Ctrl+Shift+Z、見出し右のボタン）に対応。

- **カレンダー表示**: Google カレンダー風の週ビュー（月曜始まり・24時間）。
  - 空き時間を**ドラッグ**して作成。単クリックでも 30 分の予定を作成。
  - ブロックを**中央ドラッグで移動**（別の曜日へも移動可）、**上下端ドラッグでリサイズ**。15 分単位でスナップ。
  - ブロックを**クリックで詳細編集**（説明・プロジェクト・タグ・開始/終了時刻・削除）。
  - ブロックにプロジェクト名とタグを表示。プロジェクト未設定はグレーで区別。
  - 「‹ / 今週 / ›」で週を移動。曜日ヘッダに**日別合計**、右上に**週合計**を表示。
  - 今日の列に**現在時刻ライン**（赤）を表示（1 分ごとに更新）。
- **リスト表示**: エントリを新しい順に一覧。**期間**（今日 / 今週 / 今月 / 今年 / 先週 / 先月）で絞り込み、合計時間を表示。行クリックで詳細編集。各行の 📅 ボタンで該当エントリのカレンダー（その週・時刻）へ移動。

### レポート

**期間**（今日 / 今週 / 今月 / 今年 / 先週 / 先月）と**集計軸**（プロジェクト別 / タグ別）を選んで、**円グラフ**とバーで表示。タグ別は 1 エントリが複数タグを持つ場合に各タグへ加算するため、割合の合計は 100% を超えることがあります。

### プロジェクト（⚙ ドロワー）

名前と色で管理。エントリに紐付け。削除すると関連エントリは「プロジェクトなし」に。

### データ管理（⚙ ドロワー）

- **JSON エクスポート / インポート**（バックアップ・移行用）。インポートは現在のデータを置き換えます。
- **Toggl CSV を取り込み**: Toggl Track の Detailed report（CSV）を既存データに追加で取り込み。プロジェクトは名前で照合し、無ければ自動生成します。
- **全データを削除**: 全エントリ・プロジェクトを削除（確認あり。元に戻す Ctrl+Z で復元可能）。

## データ保存

- ブラウザの `localStorage`（キー: `time-tracker-data`）に自動保存されます。
- 同じブラウザ・同じオリジンでのみ参照できます。別端末へ移すときは JSON エクスポート/インポートを使ってください。
- ブラウザのデータを消すと記録も消えるため、定期的なエクスポートを推奨します。

## CLI（`bin/tt`）

⚙ ドロワーの「ファイル同期」で接続した JSON ファイルを、ターミナルから閲覧・編集できます。Ruby 3.x の標準ライブラリだけで動きます。

```sh
export TIME_TRACKER_FILE=/path/to/time-tracker.json   # または --file PATH

tt ls                                   # 今日のエントリ（期間: today / yesterday / week / lastweek / month / lastmonth / year / all / YYYY-MM-DD）
tt add "設計レビュー" 10:00-11:30 -p LTV -t review,mtg
tt add "障害対応" 14:00-now             # 終了に now も可。-d YYYY-MM-DD で日付指定
tt edit 3f2a -s 13:00-14:00 -m "説明を変更"   # ID は ls の先頭 8 文字の前方一致
tt edit 3f2a -p ""                      # プロジェクトを外す
tt rm 3f2a
tt report week --by tag                 # 集計（--json で機械可読）
tt view                                 # 今週をカレンダー表示（today / lastweek / YYYY-MM-DD も可。--slot 15 で細かく）
tt projects / tt project add 名前 / tt tags
```

- プロジェクトは名前で指定します（大文字小文字は区別しません）。存在しない名前はエラーになるので `tt project add` で先に作ります。
- 書き込みは一時ファイル経由で置き換えるため、途中で中断してもファイルは壊れません。
- ブラウザ側は、タブに戻ったときにファイルが外部で更新されていれば自動で読み込みます。ブラウザでの編集を保存する時点でファイルが外部で更新されていた場合は、上書きするか読み込むかを確認します。
- WSL から Windows の Google ドライブ（例: `G:`）上のファイルを扱うときは、先にマウントします: `sudo mkdir -p /mnt/g && sudo mount -t drvfs G: /mnt/g`
